# 背景相近的正常记录与条件校准

本实验从六列表格取第 1、5 列寻找背景相近的正常记录，沿用第 2、3、6 列的原三列异常分数。每个待测样本的局部参考为训练集中背景最接近的 k 条正常记录。估计邻域内异常分数的加权第 99 百分位，按邻域的有效样本数向全局分位数收缩。如果一个高分在该邻域较常见，同一个原始分数在调整后会下降。

## 复现

使用选做一的 Python 环境，在本目录运行以下命令。将 `--thyroid` 的参数替换为原课程数据压缩包的实际路径。

```powershell
$out = Join-Path $env:TEMP ('thyroid_subgroup_' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff'))
python run_subgroup.py freeze --thyroid 'D:/数据路径/thyroid.zip' --output $out
python run_subgroup.py evaluate --thyroid 'D:/数据路径/thyroid.zip' --output $out
python predict_subgroup.py --model (Join-Path $out 'subgroup_model.joblib') --values -1.082333720071735 -0.15280509003829099 0.24374268267193666 -0.1532988415335525 -0.3916414902550237 0.05513767816060435
```

`freeze` 仅读取正常训练数据，写入训练各折统计、选择依据与可加载模型。`evaluate` 先验证源码、事前规则与模型哈希，保存逐样本原始分数、校正倍数、最终分数与预测，再关联课程标签。将本目录加入 Python 的模块搜索路径后，可用 `joblib.load` 加载 `subgroup_model.joblib` 并调用 `model.predict(x)`。x 应是包含全部六列的二维矩阵。

## 结果

训练内最终选择 256 个近邻、256 条全局等效参考。外层留出的 1,425 条正常记录中，原三列与局部模型均误报 4 条。弱、强两档联合扰动的平均模拟检出率分别为原三列 27.61%、局部模型 27.86%。每个受体保留自己的背景，其他四列沿背景匹配的两个正常供体间的联合差值移动。

课程测试上，局部模型出现 4 个误报、7 个漏判，F1 为 94.05%，平均精确率 AP 为 0.9638。原三列模型为 5 个误报、1 个漏判，F1 为 96.875%，AP 为 0.9633。局部调整使精确率从 94.90% 提高到 95.60%，召回率从 98.94% 降至 92.55%。
